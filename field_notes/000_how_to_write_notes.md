# How to write field notes

Write short notes only when a future session would decide differently after reading them.

Include:
- Context
- What happened
- What to do next time
- Whether this is still a candidate, not a hard rule


Private fixture references use anonymous case labels and `<private-input>`,
`<private-output>` or `<private-reference>` placeholders. These labels are not
actual filenames or runnable paths. Keep original song/file names, identifying
paths and private-file hashes only in ignored local evidence, not in tracked
notes or note filenames. Public fixture and external-tool identifiers may remain.
